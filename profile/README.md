# Holobond

**AI companions with persistent memory.** A companion that stays the same person over years, remembers what you have told it, and keeps that memory on your own computer.

- Product: [holobond.ai](https://holobond.ai) · Holo-Lite at [lite.holobond.ai](https://lite.holobond.ai) (public launch November 17, 2026)
- Non-explicit by design, enforced in code. Identity-verified adults only.
- Built in Castle Rock, Colorado.

## What we work on

- Memory and personality continuity for companion AI on small open models and on the user's own hardware.
- Measured engineering: pre-registered experiments, blind scoring, a deterministic regression bench that gates every deploy, and failures logged next to successes.
- Safety as code: crisis-language detection mapped to clinical screening items, reply screening, and age verification before an account exists.

## Open source

Holobond's product code is private. Reusable tooling that comes out of the work (evaluation harnesses, data-hygiene checks, documentation tools) will be published here under open licences as it matures. Watch this organization for releases.
